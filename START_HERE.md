# Inicio del proyecto Apex Performance Agency en Google Antigravity

Este workspace contiene todo el contexto inicial. No presupongas conversaciones anteriores.

## Fuentes de contexto

1. `AGENTS.md`: reglas, alcance y arquitectura obligatoria del proyecto.
2. `docs/Especificacion_Apex_Antigravity.pdf`: especificación funcional y visual.
3. `docs/referencias/`: capturas de la página actual.
4. Sitio actual de referencia: https://apexperformanceagency.digital/

## Primera tarea

Antes de escribir código:

1. Lee completamente `AGENTS.md`.
2. Lee `docs/Especificacion_Apex_Antigravity.pdf`.
3. Revisa todas las imágenes de `docs/referencias/`.
4. Examina la página actual únicamente como referencia de contenido e identidad; no la copies literalmente.
5. Crea un Implementation Plan con arquitectura, estructura de carpetas, fases, riesgos, datos pendientes y criterios de aceptación.
6. Espera aprobación antes de desplegar o cambiar DNS.

## Prompt inicial para el chat del agente

Lee primero `AGENTS.md`, `START_HERE.md`, el PDF de especificación y todas las capturas de `docs/referencias/`. Este es un workspace nuevo y no tienes ningún contexto previo. Resume en 10 puntos lo que entendiste, identifica los datos faltantes y genera un Implementation Plan. No escribas código hasta presentar el plan. No despliegues ni modifiques el dominio.
